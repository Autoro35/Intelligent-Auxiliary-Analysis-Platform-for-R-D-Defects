# 轻量化研发缺陷全生命周期管理与智能辅助分析平台
## 一、项目定位与具体应用场景
### 目标用户
10-30人规模的中小软件研发团队、高校软件实训/创新实验室团队、初创公司技术组
### 核心痛点
- 专业缺陷管理工具（如Jira）配置复杂、功能过重，小团队学习成本高，难以落地
- 缺陷提交不规范，分类、优先级判定全靠人工，重复沟通多，处理效率低
- 同类缺陷反复出现，历史经验难以沉淀，新人重复踩坑
- 缺陷处理进度不透明，跨角色协作（开发/测试/产品）信息不对称

### 项目价值
打造一款轻量化、开箱即用的缺陷管理工具，覆盖缺陷从提交到归档的全生命周期流程，同时用AI能力解决人工分类慢、经验难沉淀的痛点，真正提升中小团队研发效率。

## 二、核心技术栈
- **后端**：Spring Boot 3.x + MySQL + Redis + RabbitMQ + MyBatis-Plus + 规则引擎
- **前端**：Vue3 + Element Plus + ECharts
- **架构模式**：分层单体架构，模块化设计，预留微服务拆分能力

## 三、整体架构设计（软件工程核心体现）
采用经典分层架构，职责清晰，耦合度低，完整体现软件设计的高内聚低耦合原则：
1. **接入层**：前端Web页面、OpenAPI接口、第三方系统Webhook接入（GitLab/GitHub）
2. **业务层**：缺陷管理模块、项目权限模块、统计分析模块、知识库模块，通过工作流引擎解耦状态流转逻辑
3. **中间件层**：Redis缓存热点数据、RabbitMQ异步处理通知与批量操作、规则引擎配置缺陷流转规则
4. **数据层**：MySQL存储业务核心数据、Chroma轻量向量数据库存储缺陷知识库向量
5. **智能服务层**：统一封装大模型调用能力，管理Prompt模板、RAG检索逻辑，与业务层解耦

## 四、核心功能实现
### （一）主体软件工程功能
1. **缺陷全生命周期工作流**
   支持缺陷的提交、分配、受理、修复、复测、关闭、驳回、归档全状态流转，可自定义不同项目的缺陷流转规则；支持附件上传、评论追溯、操作日志全程留痕。
2. **多项目与权限管理**
   支持多项目数据隔离，内置管理员、测试人员、开发人员、访客四种角色，细粒度控制页面与数据权限，支持团队成员批量管理。
3. **缺陷统计与可视化仪表盘**
   多维度统计缺陷趋势、模块分布、人员负载、修复时效、 reopen率等核心指标，生成可视化报表，支持按周期导出。
4. **缺陷知识库管理**
   支持将已关闭的优质缺陷沉淀为知识库条目，按根因类型、解决方案标签化分类，支持关键词检索，形成团队经验资产。
5. **第三方集成能力**
   对接Github，实现代码提交与缺陷ID关联，自动更新缺陷状态；支持邮件、站内信双渠道通知提醒。

### （二）AI智能增强功能
所有功能均基于「大模型调用+规则校验+知识库检索」实现，无需模型训练，开发成本低，业务价值明确。
1. **缺陷自动分类与优先级判定**
   根据缺陷标题、描述、附件信息，自动识别缺陷类型（功能Bug、性能问题、UI异常、兼容性问题、建议优化），并结合影响范围自动判定优先级（紧急/高/中/低），人工可修正。
2. **缺陷根因与解决方案推荐**
   基于向量检索匹配历史知识库中的相似缺陷，Top3推荐可能的根因分类与对应的解决方案，辅助开发人员快速定位问题。
3. **缺陷描述智能补全与规范提示**
   用户提交缺陷时，自动识别描述完整性，提示补充复现步骤、环境信息、预期结果等关键字段，提升缺陷提交质量。
4. **代码提交风险提示**
   关联Git提交记录时，分析提交的代码改动范围与描述，提示可能引入的缺陷风险，提醒测试人员重点关注。
